# AniMind AI Agent

A production-ready AI Agent built with Google ADK and Gemini 2.5 Flash.

## Live Demo
https://zoo-tour-guide-83063886786.europe-west1.run.app

## Built With
- Google ADK (Agent Development Kit)
- Gemini 2.5 Flash
- Google Cloud Run
- Wikipedia API

## Features
- Answers any question on any topic
- Real-time Wikipedia search
- Supports Hindi and English language
- Serverless deployment on Cloud Run

## Project Structure
- agent.py - Main AI agent
- requirements.txt - Python dependencies
- .env - Environment configuration
